# Pico Sprite
After playing with mehxel.art with the kids at the CodeJoy booth at the 2026 Louisville Maker Faire, and then finding out that the Raspberry Pi Pico can directly output DVI video, I just had to make my own.

The plan is to make, basically, a _Very_ simple Paint program that runs on a Raspberry Pi Pico 2 plugged into a TV via HDMI. It will use a generic SNES style USB controller for input. I would love to expand it to be able to save files online or otherwise but I don't know quite how that could work yet.

Hardware:
- Raspberry Pi Pico 2 WH
- Adafruit HSTX DVI Cowbell [link](https://www.adafruit.com/product/6363)
- Adafruit Female Headers for Pi Pico [link](https://www.adafruit.com/product/5583)
- Adafruit USB A Host cable [link](https://www.adafruit.com/product/4449)
- Adafruit SNES style USB Controller [link](https://www.adafruit.com/product/6285)
- Mini HDMI to HDMI cable

The Pico was left over from an earlier trip to Micro Center. The Adafruit items were purchased from DigiKey because at least one was out of stock at Adafruit's website. I wish I had got the HDMI cable from Adafruit too but I forgot about it and had to grab one from Best Buy.
